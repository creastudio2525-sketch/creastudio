# 高さ計算（縦断）

[ブラウザで開くための HTML](dist/index.html) に、画面と計算処理がまとまっています。PC ではこのファイルをブラウザで開けます。配信する場合も同じファイルを使用します。

## 入力と保存

1. サンプル路線で操作を確認するか、「新規路線」を作成します。
2. 高さが分かっている測点を入力点に登録します。最低 2 点必要です。
3. 高さを求めたい測点を計算点に入力します。起点・終点の前後は端の勾配で延長します。
4. 勾配変化点に縦断曲線を設ける場合は、入力点に PVI の高さと曲線長を登録します。同じ測点を計算点にも入れると曲線上の高さを確認できます。
5. 路線は現在のブラウザに自動保存されます。別の端末に移すときは「路線設定」のバックアップを保存し、移動先で「路線を読み込む」を選びます。

SP 形式および数字のみの測点は累加距離 (m) です。No. 形式は路線設定の測点間隔で換算します。初期値 20 m の場合、`No.8+5.5` は 165.5 m です。

縦断曲線は対称放物線です。曲線長を L、曲線始点からの距離を x、前後の勾配を小数で g₁、g₂ とすると、計画高は `H = H_BVC + g₁ x + (g₂ − g₁) x² / (2 L)` で求めます。 [Caltrans の縦断曲線計算資料](https://dot.ca.gov/-/media/dot-media/programs/engineering/documents/bridgedesigndetails/chapter-2/202502bdd23attchment2dverticalcurvecalculationsa11y.pdf)

## 開発

Node.js で `node --test` を実行してから、`node build.cjs` で `dist/index.html` を生成できます。外部パッケージは不要です。
